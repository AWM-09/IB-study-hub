# November Mocks — IB Revision Studio

A single-page, GitHub Pages-compatible study website for:
- ESS SL
- Maths AI SL
- English Language & Literature HL
- Spanish Ab Initio SL
- History HL

## Features
- Dark dashboard and subject rooms
- Starter topic notes and learning checklists
- Multiple-choice practice with feedback and score tracking
- Interactive flashcards with known/review-again ratings
- Revision timetable
- Progress analytics
- Personal notes per subject/topic
- Browser-local persistence via localStorage
- Export/import progress JSON backup
- Responsive desktop/mobile layout

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `november-mocks-study`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages URL to appear.

No build step, server, API key, or dependency installation is required.

## Important
- Progress is saved in the current browser on the current device. It does not automatically sync between devices.
- Starter topics are deliberately generic. Verify the exact mock syllabus and add class-specific notes before relying on this as your complete revision resource.
- The quiz set is an initial scaffold, not a full official IB question bank. English and History extended responses require rubric-based human/AI feedback for meaningful marking.
